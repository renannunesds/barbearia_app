📱 TítuloBarberApp: Sistema Mobile para Agendamento e Gestão de Barbearia👥 EquipeRenan Nunes de Souza   Daniel Francisco de Maria da Fonseca Rincon   Ryan Victor Carvalho de Oliveira   🎯 ObjetivoDesenvolvimento de um aplicativo móvel multiplataforma (Android/iOS) utilizando a framework Flutter e a linguagem Dart. O aplicativo atuará como a interface front-end mobile, consumindo a API RESTful desenvolvida previamente em Spring Boot, visando automatizar e centralizar os agendamentos e a gestão operacional da barbearia.💈 Público-alvoClientes: Usuários que buscam agendar, acompanhar o histórico e cancelar cortes de cabelo e barba diretamente pelo smartphone, de forma autônoma.Barbeiros: Profissionais que necessitam de uma ferramenta prática para visualizar a agenda diária e atualizar o status dos serviços prestados em tempo real.⚙️ RequisitosRequisitos Funcionais (RF):RF01: O usuário deve realizar cadastro e autenticação (login) no aplicativo.RF02: O usuário deve visualizar a lista de barbeiros e os serviços disponíveis.RF03: O usuário deve selecionar datas e horários livres para confirmar um agendamento.RF04: O usuário deve consultar seu histórico de agendamentos e solicitar cancelamentos.RF05: O barbeiro deve acessar sua agenda diária e alterar o status dos atendimentos (ex: pendente, concluído, cancelado).Requisitos Não Funcionais (RNF):RNF01: O aplicativo será construído na framework Flutter (linguagem Dart).RNF02: A comunicação de dados ocorrerá via requisições HTTP, consumindo os endpoints da API.RNF03: A interface utilizará componentes nativos do Material Design, implementando navegação intuitiva por abas (BottomNavigationBar).📊 Diagramas1.
